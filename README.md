# دهب دكتور (Dahab Device Doctor) 🏥

## المنظومة الأكثر تقدماً في الشرق الأوسط لتشخيص وصيانة الإلكترونيات

منصة متكاملة متعددة المحركات الذكاء الاصطناعي لفحص وصيانة الموبايل، اللابتوب، الشاشات، كروت الباور والكنترول.

---

## ✨ الميزات الرئيسية

### 🤖 محركات ذكاء اصطناعي متعددة
- **OpenAI GPT-4o** - المحرك الأساسي والأقوى
- **OpenRouter GLM-5.2** - محرك بديل متقدم
- **Google Gemini 1.5 Flash** - محرك احتياطي
- **المحرك المحلي** - يعمل بدون إنترنت

### 🔧 الأدوات الهندسية الخمس
1. **كاشف ومحلل الأعطال الذكي** - تشخيص هاردوير/سوفتوير
2. **محلل سجلات البانيك** - iOS/Android Panic Logs
3. **حاسبة حقن الفولت والحرارة** - Safe Injection Calculator
4. **معمل البوردفيو والمسارات** - Boardview Simulator
5. **موسوعة بدائل الآيسيهات** - IC Cross-Reference

### 🌍 ميزات الشرق الأوسط
- دعم كامل للغة العربية
- قاموس المصطلحات التقنية المحلية
- أسعار تقديرية للقطع
- قائمة الموردين المعتمدين
- تحويل العملات

### 📊 تكامل المخططات
- تحليل مسارات الباور تلقائياً
- اقتراح نقاط الفحص الذكية
- ربط الآيسيهات بالأعطال
- تقرير تكامل شامل

## 🚀 التثبيت والإعداد

### 1. تثبيت الحزم
```bash
npm install
```

### 2. إعداد مفاتيح API
أنشئ ملف `.env.local` في المجلد الرئيسي:

```env
# OpenAI API Key (GPT-4o)
OPENAI_API_KEY=your_openai_api_key_here

# OpenRouter API Key (GLM-5.2)
OPENROUTER_API_KEY=your_openrouter_api_key_here

# Google Gemini API Key (اختياري)
GEMINI_API_KEY=your_gemini_api_key_here
```

### 3. تشغيل التطبيق
```bash
npm run dev
```

افتح المتصفح على `http://localhost:3000`

## 📖 كيفية الاستخدام

### 1. اختيار محرك الذكاء الاصطناعي
- اختر المحرك المفضل من واجهة التطبيق
- النظام يختار تلقائياً الأفضل المتاح
- يمكن التبديل بين المحركات في أي وقت

### 2. إدخال بيانات الجهاز
- اختر نوع الجهاز (موبايل، لابتوب، شاشة، إلخ)
- أدخل طراز الجهاز
- صف العطل بالعربية أو الإنجليزية
- أضف قراءات الباور سبلاي إن وجدت

### 3. الحصول على التشخيص
- اضغط على "تشخيص"
- شاهد النتائج بالبث الحي
- راجع تصنيف العطل (هاردوير/سوفتوير)
- اتبع خطوات الفحص المقترحة

### 4. استخدام الأدوات الأخرى
- استخدم محلل البانيك لسجلات iOS/Android
- احسب الفولت الآمن للحقن
- استكشف البوردفيو والمسارات
- ابحث عن بدائل الآيسيهات
